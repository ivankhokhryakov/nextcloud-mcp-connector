## Antwortentwurf Issue #15 (NICHT gepostet)

> Thanks for the report. This is coming with the next release:
>
> - New deploy variable `NC_MCP_DISABLED_TOOLS`, comma separated bundle names.
> - For your setup with Zimbra: `NC_MCP_DISABLED_TOOLS=mail,calendar` removes `mail_browse`, `calendar_list_events` and `calendar_create_event`.
> - Valid names: calendar, chatgpt, contacts, context, deck, files, mail, notes, search, tables, talk.
> - Unset means every bundle is on, so nothing changes for existing installations.
> - An unknown name stops the app at start with a message that lists the valid names.
> - The ExApp declares the variable and logs at start which bundles are off.
> - It hides tools, it is not an access control: `search`, `fetch` and `prepare_context` can still return content of a hidden bundle.
>
> No date yet, I will post here when the release is out.
